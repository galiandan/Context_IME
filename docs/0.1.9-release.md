## 性能与验证边界

与 0.1.8 的同环境对照中，四万行插行缓存映射中位耗时降低约 11.7%；两万行字符串分散移动中位耗时约快 60 倍，扫描行数减少约 99.6%。这是对应核心基准结果，不是整个 VS Code 的 CPU/内存下降比例。测量环境、样本数和完整数据见[性能审查记录](performance-review-2026-09-27.md)。

macOS Intel/ARM64 在 GitHub Runner 上通过 Swift 类型检查、编译和包架构/执行权限验证；Windows x64/ARM64 通过 MSVC 编译和包架构验证。Windows/macOS 未进行真实桌面输入法验证；未修改本机输入法设置。凭据由已有本机 vsce 登录管理，未写入仓库。
