# 08 · 测试、构建与交付

## 1. 先验证核心，再接真实平台

先编写关键分类与控制器测试，再实现纯 TypeScript 逻辑与 Fake Adapter；随后接当前可用平台完成“真实编辑 → 分类 → 配置 → 系统源设置 → 读回”的完整流程。没有桌面会话只能做可验证的探测/协议测试，不能标真实切换通过。

| 层级 | 必验内容 |
| --- | --- |
| 分类单元 | 插入位置、嵌套 scopes、定界符、未完成代码、unknown |
| 缓存单元 | 行映射、多处 edit、状态收敛、分词调用量、取消与 LRU |
| 控制器单元 | 去重、手动接管、串行、过期、配置与焦点门控 |
| 进程单元 | 参数安全、超时、输出上限、非零退出、非法结果、未知状态 |
| VS Code 集成 | 稳定事件、设置、命令、状态栏、本地 UI 宿主 |
| 平台测试 | 原生 helper 与真实框架行为、能力探测、源读回 |
| 实机手工 | 候选词、输入控件焦点、多窗口与系统输入法内部模式 |
| 性能 | 冷暖路径、分词量、调用量、空闲、内存趋势 |

## 2. 核心用例清单

| 类别 | 必须覆盖的断言 |
| --- | --- |
| 普通字符串 | 需求中的六个 print 光标样例、单引号/双引号、空串、转义 |
| Python | 三引号、raw、f-string 文本/表达式/内嵌字符串、未闭合结构 |
| JS/TS | 模板文本、插值边界、嵌套字符串、正则内引号/斜线 |
| C/C++ | 字符按 code、普通/raw 字符串、自定义 raw delimiter、注释与续行 |
| 通用 | 注释内引号、弯引号不构成字符串、CRLF、中文、emoji、UTF-16 |
| 编辑 | 自动补齐/跳过引号、删除开闭符、粘贴、撤销/重做 |
| 增量 | 文件前部三引号改变使后缀失效；插删行映射；多 edit 不漏算 |
| 复用 | 相同文本不同状态不复用；状态收敛复用未改后缀；暖查询不扫全文 |
| 控制 | 同区域手动切英文后不强制改回；位置偏移不算新区域 |
| 竞态 | string → code → string；旧分析迟到；旧进程晚退出不得覆盖新结果 |
| 暂停 | 失焦、禁用、编辑器切换、向导、多光标、非空选区取消待执行项 |
| 降级 | 未配置、未知语言、大文件、超长行、stoppedEarly、缺依赖 grammar |
| 平台异常 | 超时、非法/空/过长输出、状态未知、缺框架、源不存在、熔断 |
| 参数安全 | 空格、非 ASCII、引号、shell 特殊字符作为一个 ID 参数传递，不执行命令 |

分类测试使用人工期望结果；缓存随机编辑测试与全量基线对照。调度使用可控 Fake Adapter 延迟、失败与不可撤销设置模型；不能仅检查最终 Promise 返回值而不检查真正执行顺序。

## 3. 焦点与候选词实机测试

拼音预编辑、候选词选择、日本语组合输入期间移动光标/关闭字符串；命令面板、终端、搜索框、Git 输入框、其他应用获得焦点时验证不因陈旧编辑器状态发起切换。多窗口 Stable/Insiders、睡眠唤醒、框架重启亦需覆盖。

记录 OS/架构、VS Code/Electron、输入法和版本、窗口权限、桌面协议、安装方式、源和系统按应用记忆设置。不修改用户系统设置来掩盖问题；任何未运行的组合写“未进行真实环境验证”。

## 5. CI 与 VSIX

流水线顺序：npm ci → lint/typecheck → 核心测试 → 构建扩展和 helper → 集成/协议测试 → 资源和许可证校验 → 平台 VSIX 打包 → 解包检查。性能 benchmark 在可比环境单列，避免共享 CI 噪声伪造稳定 p95。

Windows 包含匹配架构 helper；macOS 分 x64/arm64；Linux 包含适配器与系统工具依赖说明。目标平台名以实际 vsce 支持为准。缺对应 helper 的 Windows/macOS 构建应失败，不产生表面可安装的空功能包。[平台定向发布文档](https://code.visualstudio.com/api/working-with-extensions/publishing-extension)

VSIX 包含运行资源和第三方许可证，不包含 node_modules 开发依赖、测试大文件、编译缓存或无关平台二进制。核验离线运行、执行权限和干净机器安装；没有 Node.js/编译器的用户仍能使用已打包扩展。

## 6. 发布门槛

本轮实现只生成本地 VSIX，不自动发布 Marketplace。命名冲突、发布者、签名凭据、公证与公开发布在最终发布前另行处理。

误切其他应用、候选词丢失、无界任务、旧请求覆盖新目标、缺许可证/资源均阻断受影响组合正式发布。兼容性表严格分开实现、构建、自动测试和实机验证；保留禁用自动模式与安装旧版本的回退方式。
